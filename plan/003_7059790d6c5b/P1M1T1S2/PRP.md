# PRP — P1.M1.T1.S2: Regenerate `docs/llms_full.txt` to propagate the fix

> **Repo:** QMKonnect (`/home/dustin/projects/qmkonnect`) — THIS repo.
> **Scope:** Run one committed shell script to regenerate a generated doc file.
> No source, build, or behavior change. No hand-editing.
> **This IS the documentation regeneration** (Mode A) — `llms_full.txt` is the
> deliverable, regenerated from source by the script.

## Goal

**Feature Goal**: Regenerate the committed-but-generated `docs/llms_full.txt` so
its verbatim mirror of `docs/troubleshooting.md` (the §"Debugging the Firmware
Side" passage, currently at `llms_full.txt:2622`) picks up the S1 naming fix
(`qmk-notifier_notify` → `qmk_notifier_notify`). After regeneration, the stale
hyphen form is gone from the generated file and the underscore form appears
exactly once, matching the now-fixed source.

**Deliverable**: `docs/llms_full.txt` regenerated by `bash docs/generate_llms_full.sh`
(the committed concatenation script), with the one-character mirror change on the
troubleshooting.md passage. No other file is modified by this subtask.

**Success Definition**: After running the script from the repo root:
- `grep -n 'qmk-notifier_notify' docs/llms_full.txt` → **zero** hits (stale form
  eliminated from the generated file).
- `grep -n 'qmk_notifier_notify' docs/llms_full.txt` → **exactly one** hit (the
  mirrored, corrected token, ≈ line 2622).
- `git status --short docs/llms_full.txt` shows it modified; `git diff` shows the
  expected token change (ideally a single-line hunk; any extra hunks are
  legitimate doc-syncs that should be reviewed, not regressions).
- `docs/generate_llms_full.sh`, `docs/troubleshooting.md`, and all other source
  files are **unchanged** by this subtask.

## User Persona (if applicable)

**Target User**: Agents/LLMs (and humans) that consume the single-file
`docs/llms_full.txt` concatenation as the canonical QMKonnect reference. The file
exists specifically "for Agents / LLMs" (per the script header) so that an LLM
can ingest all docs in one read instead of walking the `docs/` tree.

**Use Case**: An agent ingests `llms_full.txt` to answer "what is the firmware
callback convention?" — it must see the corrected `qmk_notifier_notify` (underscore),
not the stale hyphen form, or it will learn/repeat the wrong convention.

**Pain Points Addressed**: The committed `llms_full.txt` had drifted out of sync
with its source (`docs/troubleshooting.md`) by exactly the one token S1 fixed.
Regeneration closes the only remaining residual drift identified by the delta
verification pass (`delta_verification.md` §Residual Drift item #2).

## Why

- **Closing residual drift.** The v0.2.8 delta verification
  (`plan/003_7059790d6c5b/architecture/delta_verification.md`) found the source fix
  in S1 sufficient for the `--include` grep filters (`.md`/`.rs`/`.toml`/`.yml`/
  `.sh`/`.ps1`), but `llms_full.txt` is a `.txt` file outside those filters and
  mirrors the stale line verbatim. Regenerating it propagates the fix to the
  generated artifact so the whole tree is consistent.
- **Single source of truth.** `llms_full.txt` is *generated* (the script is
  `docs/generate_llms_full.sh`), not hand-maintained. The correct way to fix its
  content is to fix the source (done in S1) and re-run the generator — never to
  hand-edit the generated file. This subtask does exactly that.
- **Unblocks the verification sibling.** P1.M1.T1.S3 ("Full-tree verification
  grep") runs a repo-wide grep for `qmk-notifier_notify` expecting **zero** hits.
  That grep is only clean once S2 has regenerated `llms_full.txt`. So S2 must land
  before S3.

## What

Run the committed regeneration script, then verify. Three steps, no edits to any
source file.

### Step 1 — Confirm the source is fixed BEFORE regenerating (gate)

```bash
cd /home/dustin/projects/qmkonnect
grep -n 'qmk_notifier_notify' docs/troubleshooting.md    # expect exactly one hit (line 647)
grep -n 'qmk-notifier_notify'  docs/troubleshooting.md   # expect ZERO hits (exit 1)
```

> If the source is STILL hyphen (S1 has not landed): **STOP.** Do not regenerate a
> stale source into the mirror. Regeneration is only correct once line 647 reads
> `qmk_notifier_notify`. Surface the blocker rather than re-baking the stale text.

### Step 2 — Regenerate the file (the entire deliverable)

```bash
cd /home/dustin/projects/qmkonnect

```

This re-concatenates README.md + the 7 `docs/*.md` files (front matter stripped,
each wrapped in a numbered `===` divider, troubleshooting.md is section #8) into
`docs/llms_full.txt`, overwriting it. Expected final line of stdout:
`wrote docs/llms_full.txt (<N> lines, <N> bytes)`.

### Step 3 — Verify the propagated fix (the two deterministic gates)

```bash
grep -n 'qmk-notifier_notify' docs/llms_full.txt   # MUST print nothing (exit 1)
grep -n 'qmk_notifier_notify'  docs/llms_full.txt   # MUST print exactly one line (≈2622)
```
