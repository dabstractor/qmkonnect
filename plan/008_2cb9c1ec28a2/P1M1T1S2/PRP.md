> **Repo:** QMKonnect (`/home/dustin/projects/qmkonnect`).
> **Scope:** Run ONE committed shell script to regenerate a generated doc artifact.
> No source change, no behavior change, no hand-editing. **Mode B** — this IS the

## Goal

**Feature Goal**: Regenerate the committed-but-generated `docs/llms_full.txt` so its
verbatim mirrors of `README.md` and `docs/installation.md` no longer carry the 14 stale
mise/asdf references (lines 157, 160, 490, 750–760, 828–835). After regeneration,
`grep -in 'mise\|asdf' docs/llms_full.txt` and `grep -in 'asdf-qmkonnect' docs/llms_full.txt`
both return **zero** hits — the stale references vanish entirely (not relocated), because
both source docs are clean (README already; installation.md after S1).

**Deliverable**: `docs/llms_full.txt` regenerated by `bash docs/generate_llms_full.sh`,
with the 14 stale mise/asdf lines gone. No other file is modified by this subtask.

**Success Definition**: After running the script from the repo root:
- `grep -in 'mise\|asdf' docs/llms_full.txt` → **zero** hits.
- `grep -in 'asdf-qmkonnect' docs/llms_full.txt` → **zero** hits.
- The script's stdout confirms the new line/byte count (`wrote docs/llms_full.txt (<N> lines, <N> bytes)`).
- `git status --short docs/llms_full.txt` shows it modified; `git diff` shows the expected
  mise/asdf removal (plus line shifts); any extra hunks are legitimate doc-syncs (reviewed).
- `docs/generate_llms_full.sh`, `docs/installation.md`, `README.md`, and all other source
  files are **unchanged** by this subtask.

## User Persona (if applicable)

**Target User**: Agents/LLMs (and humans) that consume the single-file `docs/llms_full.txt`
concatenation as the canonical QMKonnect reference. The file's header states it is "for
Agents / LLMs" so an LLM can ingest all docs in one read instead of walking `docs/`.

**Use Case**: An agent ingests `llms_full.txt` to answer "how do I install QMKonnect?" —
it must NOT see the stale mise/asdf instructions (the project decided mise/asdf are a
category mismatch — `spec/PACKAGING.md` §6.4, `spec/PRD.md` F15), or it will recommend a
non-channel with broken `asdf-qmkonnect` links.

**Pain Points Addressed**: The committed `llms_full.txt` had drifted out of sync with its
sources: the README mirror (lines 157/160) was a snapshot of an old README, and the
installation.md mirror (490, 750–760, 828–835) reflected the 3 mise/asdf blocks S1 removed.
Regeneration resyncs the generated artifact with the now-clean sources.

## Why

- **Single source of truth.** `llms_full.txt` is *generated* (the script is
  `docs/generate_llms_full.sh`), not hand-maintained. The correct way to fix its content is
  to fix the sources (README already clean; installation.md via S1) and re-run the generator
  — never to hand-edit the generated file.
- **Closes the doc-sync loop for the mise/asdf removal.** S1 fixed the user-facing source
  (`docs/installation.md`); the `stale_content_audit.md` §2 mapped the generated mirror's
  stale lines (490, 750–760, 828–835) to those exact blocks. S2 propagates the fix to the
  generated artifact so the whole tree is consistent.
- **README-derived staleness clears for free.** Lines 157/160 mirror an OLD README snapshot;
  the live README is already clean (0 mise/asdf hits), so regenerating clears them without
  any README edit.
- **Deterministic verification.** Two greps (zero `mise|asdf`, zero `asdf-qmkonnect`) are the
  unambiguous definition of "done" — line-number-independent.

## What

Run the committed generator AFTER confirming the sources are clean, then verify. Three
steps, no edits to any source file.

### Step 1 — GATE: confirm both source docs are clean BEFORE regenerating


### Step 2 — Regenerate the file (the entire deliverable)


configuration,usage,examples,troubleshooting}.md`; front matter stripped; each wrapped in a
numbered `===` divider) into `docs/llms_full.txt`, overwriting it. Expected final stdout
line: `wrote docs/llms_full.txt (<N> lines, <N> bytes)`. Non-zero exit (`set -euo pipefail`)

